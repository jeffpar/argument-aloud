# Docket Search

The Court's **Docket Search** page (shown below) provides details for most 21st century cases (2001 onward), as well as some earlier cases (e.g., [Original Jurisdiction](/courts/ussc/?collection=orig) cases that had activity since 2001).

While their page is self-explanatory, one important detail it neglects to mention is how to search for cases on the Court's **Original Jurisdiction** docket.  Those cases are assigned identifiers such as "142 Original," which is usually abbreviated as "142 Orig."  Unfortunately, searching for either of those identifiers will generally fail.

To reliably find *any* such case, you must use an undocumented prefix, "22O" ("22" followed by the letter "O"), followed by the Original Jurisdiction case number.  So, to find case "142 Orig.", you should actually search for "22O142."
